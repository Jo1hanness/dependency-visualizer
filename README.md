# dependency-visualizer

Практическая работа №2 по «Конфигурационному управлению», вариант 15.

Консольная программа, которая строит граф зависимостей пакета Ubuntu
(apt). Зависимости достаются из индекса репозитория `Packages` без apt
и без сторонних библиотек, только стандартный Python.

Этапы работы лежат в ветках `stage1` – `stage5`, итог в `main`.

## Настройки

Параметры задаются в файле `config.csv` (строки `параметр,значение`):

- `package_name` — имя пакета (в тестовом режиме — большие латинские буквы);
- `repository` — URL индекса `Packages`/`Packages.gz` или путь к файлу;
  в тестовом режиме — путь к файлу с описанием графа;
- `test_mode` — `true`/`false`, работа с тестовым репозиторием;
- `package_version` — версия пакета (в тестовом режиме можно пустой);
- `ascii_tree` — `true`/`false`, вывести зависимости деревом;
- `reverse_mode` — необязательный, `true` — вывести обратные зависимости.

Все параметры проверяются, при ошибке программа пишет причину и
завершается с кодом 2. Примеры неправильных конфигов — в `examples/errors`.

Пример для настоящего репозитория — `examples/config_apt.csv`.

## Что умеет

1. Читает и проверяет конфиг.
2. Находит прямые зависимости нужной версии пакета (поля `Depends` и
   `Pre-Depends`; из альтернатив `a | b` берётся первая, ограничения
   версий отбрасываются, виртуальные пакеты заменяются через `Provides`).
3. Строит граф транзитивных зависимостей обходом в ширину (BFS) без
   рекурсии. Каждый пакет посещается один раз, поэтому циклы не мешают,
   а найденный цикл выводится отдельно.
4. Тестовый режим: граф из файла вида `A: B C` (примеры в `examples/repo_*.txt`).
5. Обратные зависимости — тот же BFS по перевёрнутым рёбрам.
6. Визуализация: описание графа на Mermaid сохраняется в `graph.mmd`,
   картинка открывается на экране (`graph.png` через `mmdc`, если он
   установлен, иначе `graph.html`). При `ascii_tree=true` ещё и дерево.

## Запуск и тесты

Нужен Python 3.8+.

```sh
./run.sh                          # берёт config.csv
./run.sh examples/config_cycle.csv
make test                         # тесты (unittest)
```

## Примеры

```text
$ ./run.sh examples/errors/bad_bool.csv
Ошибка конфигурации: test_mode: ожидалось true/false, получено 'maybe'

$ ./run.sh examples/config_cycle.csv
Граф зависимостей A (обход BFS):
  A -> B, D
  B -> C
  D -> —
  C -> A
Обнаружен цикл: A -> B -> C -> A

$ ./run.sh examples/config_reverse_simple.csv
Обратные зависимости D (обход BFS):
  D <- B, C
  B <- A
  C <- A
Всего зависящих пакетов: 3
```

Визуализация для трёх пакетов: `examples/config_viz_curl.csv`,
`config_viz_wget.csv`, `config_viz_libssl3t64.csv`.
`examples/Packages_sample` — кусок индекса Ubuntu 24.04 для запуска без сети.

## Сравнение с apt

Проверял через `apt-cache depends`, `apt-cache rdepends`, `apt-rdepends`
и `debtree`. Отличия есть, и они ожидаемые:

- apt и debtree показывают ещё `Recommends`/`Suggests`, а я беру только
  обязательные `Depends` и `Pre-Depends`;
- из альтернатив `a | b` у меня только первая, apt показывает все;
- виртуальные пакеты apt выводит как `<имя>`, у меня они сразу заменены
  на пакет, который их предоставляет;
- для транзитивных зависимостей я не учитываю ограничения версий;
- читается один индекс (например, `main`), а apt смотрит все подключённые
  репозитории, поэтому часть пакетов может оказаться «нет в репозитории»;
- debtree по умолчанию скрывает базовые пакеты вроде `libc6`, у меня они есть.
